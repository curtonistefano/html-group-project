Il nostro sito

Questa pagina è stata creata da 4 ragazzi del liceo per informarvi meglio sulle fake news ovvero delle notizie false che mettono in difficolta i web surfers come voi! in questa pagina troverete definizione di fake news, l'uso di tecniche manipolative dei giornali e come difendersi dalle fake news! per creare questa pagina di informazioni su questo tema così attuale è stata utilizzato html e css due linguaggi di programmazione utili per creare pagine sul web e per molto altro. inoltre è stata utilizzato GitHub che ci ha garantito l'host per il sito. GitHub è un sito che vi permette di programmare con diverse lingue di programmazione quali C, C++ python java, java script e HTML e CSS, ma non è questo il bello, infatti GitHub vi permette di programmare con altre persone online per la creazione di un progetto in comune!
