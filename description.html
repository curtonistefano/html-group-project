Questo sito

Chi

Questa pagina è stata creata da 4 ragazzi del liceo per informarvi meglio sulle fake news ovvero delle notizie false che mettono in difficolta i web surfers come voi!

Cosa

In questa pagina troverete definizione di fake news, l'uso di tecniche manipolative dei giornali e come difendersi dalle fake news!

Come

Per creare questa pagina di informazioni su questo tema così attuale sono stati utilizzati HTML e CSS, due linguaggi di programmazione creati per progettare pagine sul web.

Abbiamo utilizzato Github, che gestisce l'hosting statico per il sito.

Github

Github è stato chiave nella realizzazione di questo progetto.

Si tratta di un sito che permette di gestire repository git, ovvero cartelle di file con piccole aggiunte che sono molto utili per sviluppare codice.

Tra queste ci sono: una cronologia, supporto per collaborare a distanza e l'hosting statico.
